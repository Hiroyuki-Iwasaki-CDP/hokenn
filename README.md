# わが家の保険

保険証券や契約内容を登録すると、誰の・何に備える・どの保険会社の・いくらの保障かを、カードや図で一目で把握できるWebアプリです。

## 特徴

- ダッシュボード: 家族ごとの切り替え、保障分野ごとの「保障の全体像」、保険期間タイムライン、更新・満期の予定
- 保険一覧: カード表示、家族・保障分野・保険会社・契約状態での絞り込み
- 保険詳細: 契約者/被保険者、主契約、特約、保障額、保険料、契約期間、解約返戻金、受取人、連絡先などを区分表示
- 登録・編集: 8ステップのウィザード形式の入力フォーム
- 保障を比べる: 同じ人・同じ分野の契約を積み上げ棒グラフで比較(重複の可能性を中立的に表示するのみで、解約・加入は提案しません)

## 開発環境での起動

```bash
npm install
npm run dev
```

`http://localhost:5173/` を開くと、架空のサンプルデータ(4契約)入りの状態からすぐに確認できます。

## ビルド

```bash
npm run build
```

## データの保存について

入力したデータはブラウザのlocalStorageにのみ保存され、外部には送信されません。アクセス解析や広告用のスクリプトは含まれていません。

## 注意事項

このアプリは保険・法律・税務上の助言を行うものではありません。ご契約内容の確認は保険証券や保険会社にお問い合わせください。
